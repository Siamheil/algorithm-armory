<h2><a href="https://www.geeksforgeeks.org/problems/sum-unique-elements--160334/1">Sum Unique Elements</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given an array <strong>arr[]</strong>, return the sum of elements whose frequency is 1.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = [1, 1, 2, 2, 4]
<strong>Output: </strong>4
<strong>Explanation: </strong>The frequency of elements is 1: 2, 2: 2, 4:1. Here, only 4 has frequency of 1 so it is the sum.</span> </pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = [3, 3, 1, 2, 4, 8, 8]
<strong>Output: </strong>7
<strong>Explanation: </strong>The frequency of elements is 1: 1, 2: 1, 3: 2, 4:1, 8: 2. Here, only 1, 2, 4 has frequency of 1 so the sum is 1 + 2 + 4 = 7.</span> </pre>
<p><span style="font-size: 18px;"><strong>Constraints:<br></strong></span><span style="font-size: 18px;">1 ≤ arr.size() ≤ 10<sup>4</sup><br>1 ≤ arr[i] ≤ 10<sup>9</sup></span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>STL</code>&nbsp;
